# Paseo 任务看板中心

插件在自己的进程里运行中心、网页和 MCP，采集选中主机的会话。关闭 app 后，采集器仍在后台运行。

插件读取本机和本机 daemon 已登记的一跳主机，将会话元数据、对话文本和有长度限制的工具详情直接写入本机中心。中心可能按自己的设置使用模型服务生成摘要。连接恢复后，每个来源从中心确认的位置接着同步。

## 使用条件

需要 Paseo 0.17 以上和 Node 26 以上，从准备好依赖的本地检出按路径安装。每个 daemon 有自己的私有配置、令牌与数据库身份记录，首次生成的配置仅监听本机。详见[安装说明](README.md)。

## 采集设置

可以逐台勾选或全选主机。默认只采已关闭和已归档会话的元数据；打开历史读取后，可以在设置页查看进度。读取可能加载 provider 运行时，归档标记会保留。

插件以 daemon 账户的权限访问文件系统和网络，读取配置、保存待确认批次和本地状态、查询仓库状态并向中心上报。未提交变更只上报文件数。用于精确计数的可选接口不可用时，对话采集仍可继续。插件不给 agent 发送提示词。
